# InkMyNovel Uploader

โปรแกรมอัปโหลดตอนนิยายไปยัง MyNovel แบบกึ่งอัตโนมัติด้วย `Selenium` และ `PyQt6`

## ไฟล์สำคัญในโปรเจกต์
- `inkxmynovel_pyqt.py`
  - ไฟล์หลักของโปรแกรม
- `requirements.txt`
  - รายการแพ็กเกจที่ต้องติดตั้ง
- `install.bat`
  - สร้าง virtual environment และติดตั้ง dependencies
- `run.bat`
  - ใช้รันโปรแกรมบน Windows

## ความสามารถหลัก
- อัปโหลดตอนจากไฟล์ `.txt` ไปยัง MyNovel
- ใช้บรรทัดแรกของไฟล์เป็น `ชื่อตอน` ตาม logic เดิม
- ตั้งราคาตอนแบบฟรี, ติดเหรียญ, หรือ `auto free`
- ตั้งสถานะเผยแพร่แบบร่าง, เผยแพร่ทันที, หรือตั้งเวลาล่วงหน้า
- รองรับหลายงานนิยายในหน้าจอเดียว
- รองรับ `Automation Profile` สำหรับเก็บ session login เพื่อใช้ซ้ำ
- มีปุ่ม `เปิดหน้า Login MyNovel` เพื่อ login ก่อนแล้ว reuse session ได้
- มีโหมด `รันเรื่องที่เลือก`
- มีโหมด `รันทั้งหมด (คิว)` แบบทีละเรื่อง
- มีโหมด `รันพร้อมกัน` แบบเปิด browser แยกต่อเรื่อง
- มีระบบ verify ก่อนอัปโหลดและหลังอัปโหลดเพื่อลดปัญหาข้ามตอนหรือลงซ้ำ

## การติดตั้ง
1. ติดตั้ง Python 3 บน Windows
2. ดับเบิลคลิก `install.bat`
3. รอให้ระบบติดตั้ง dependencies ให้เสร็จ

หรือใช้คำสั่ง:

```bat
py -3 -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

## การใช้งาน
1. รัน `run.bat`
2. เลือก profile mode ที่ต้องการ
3. ถ้าต้องการ reuse session ให้กด `เปิดหน้า Login MyNovel` แล้ว login ให้เสร็จก่อน
4. เพิ่มงานนิยายทาง panel ด้านซ้าย
5. ตั้งค่าของแต่ละเรื่อง เช่นชื่อเรื่อง, URL เรื่อง, ไฟล์ `.txt`, ราคา, schedule, auto free
6. เลือกโหมดการรันที่ต้องการ

## โหมดการรัน
- `รันเรื่องที่เลือก`
  - รันเฉพาะ task ที่เลือกอยู่ในรายการ
- `รันทั้งหมด (คิว)`
  - รันทุก task ทีละเรื่องบน flow เดียว
- `รันพร้อมกัน`
  - รันหลาย task พร้อมกัน โดยเปิด browser แยกต่อเรื่อง
  - แนะนำให้ใช้ `Automation Profile` หรือ profile ที่ login ไว้แล้ว

## Automation Profile คืออะไร
`automation_profile/` คือโฟลเดอร์ local ที่โปรแกรมใช้เก็บ Chrome profile สำหรับ automation โดยเฉพาะ

ใช้สำหรับ:
- เก็บ session login ของ MyNovel ไว้ใช้ซ้ำ
- ช่วยให้ไม่ต้อง login ใหม่ทุกครั้ง
- ใช้เป็นต้นทางสำหรับเปิด browser เพิ่มในโหมด parallel

โฟลเดอร์นี้เป็นข้อมูลเฉพาะเครื่องและอาจมี cookie / session / cache ของผู้ใช้จริง

ดังนั้น:
- **ไม่ควร push ขึ้น git**
- **ไม่ควรแชร์ให้คนอื่น**

## ระบบตรวจสอบตอนก่อนอัปโหลด
โปรแกรมจะพยายามอ่านข้อมูลจากตารางตอนในหน้า MyNovel แล้วตรวจสอบว่า:
- ตอนล่าสุดบนเว็บต่อกับไฟล์แรกที่จะอัปโหลดจริง
- ไม่กำลังลงตอนซ้ำกับตอนล่าสุดบนเว็บ
- หลัง submit แต่ละตอน เว็บมีตอนใหม่เพิ่มจริง

เป้าหมายคือช่วยลดปัญหา:
- ข้ามตอน
- ลงไม่ครบ
- ลงซ้ำ
- หน้าเว็บค้างแล้วสคริปต์วิ่งต่อผิดลำดับ

## รูปแบบไฟล์ตอน
แนะนำให้ใช้ไฟล์ `.txt` หนึ่งไฟล์ต่อหนึ่งตอน

แนวทางที่แนะนำ:
- บรรทัดแรก = ชื่อตอน
- บรรทัดถัดไป = เนื้อหาตอน
- ชื่อไฟล์หรือชื่อตอนควรมีเลขตอน เช่น `ตอนที่ 486` เพื่อให้ระบบ verify ทำงานได้แม่นขึ้น
