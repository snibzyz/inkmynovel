# InkMyNovel Uploader

โปรแกรมอัปโหลดตอนนิยายไปยัง MyNovel แบบกึ่งอัตโนมัติด้วย `Selenium` และ `PyQt6`

## ไฟล์สำคัญในโปรเจกต์
- `inkxmynovel_pyqt.py`
  - ไฟล์หลักของโปรแกรม
- `requirements.txt`
  - รายการแพ็กเกจที่ต้องติดตั้ง
- `install.bat`
  - สร้าง virtual environment และติดตั้ง dependencies
- `run.bat`
  - ใช้รันโปรแกรมบน Windows

## ความสามารถหลัก
- เลือกนิยายจากหน้าแดชบอร์ด MyNovel
- เพิ่มตอนอัตโนมัติจากไฟล์ `.txt`
- ตั้งชื่อและวางเนื้อหาตอนอัตโนมัติ
- ตั้งราคาตอนแบบฟรี/เสียเงิน/auto free
- ตั้งสถานะเผยแพร่แบบร่าง, เผยแพร่ทันที, หรือตั้งเวลา
- มี log สำหรับช่วยตรวจสอบขั้นตอนการอัปโหลด

## การติดตั้ง
1. ติดตั้ง Python 3 บน Windows
2. ดับเบิลคลิก `install.bat`
3. รอให้ระบบติดตั้ง dependencies ให้เสร็จ

หรือใช้คำสั่ง:

```bat
py -3 -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

## การใช้งาน
1. เปิด Chrome และล็อกอิน MyNovel ให้เรียบร้อย
2. รัน `run.bat`
3. ตั้งค่าการอัปโหลดในหน้าจอโปรแกรม
4. เลือกโฟลเดอร์หรือไฟล์ตอนนิยายที่ต้องการอัปโหลด
5. เริ่มอัปโหลด

## รูปแบบไฟล์ตอน
แนะนำให้ใช้ไฟล์ `.txt` หนึ่งไฟล์ต่อหนึ่งตอน โดยบรรทัดแรกหรือรูปแบบภายในควรตรงกับที่โปรแกรมรองรับอยู่ในปัจจุบัน

## หมายเหตุ
- โปรเจกต์นี้ **ไม่รวม** ไฟล์ตั้งค่าจริงของผู้ใช้ เช่น `config.json`
- โปรเจกต์นี้ **ไม่รวม** รายการนิยายส่วนตัว, progress log, archive และ virtual environment
- หากต้องการใช้งานจริง ควรสร้างค่าตั้งต้นใหม่จากในโปรแกรมหลังเปิดใช้งาน

## Dependencies
- `selenium`
- `PyQt6`
